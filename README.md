# 🌸 About

**Sakura Launcher** is a modern launcher built for **Linux**, designed to simplify the execution and management of applications.

Originally created to make running Windows applications through **Wine** easier, Sakura has evolved into a lightweight launcher capable of organizing multiple application types in a clean and intuitive interface.

Instead of searching folders, opening terminals and typing commands every time you want to launch an application, Sakura keeps everything organized in a single library.

Its goal is **not** to replace projects like **Wine**, **Proton**, **Steam** or **Lutris**.

Instead, it works alongside them to provide a faster, cleaner and more enjoyable experience.

---

# 🌸 Philosophy

> **"If the launcher can do it for you, you shouldn't have to do it manually."**

Sakura Launcher was built around three simple ideas.

### 🌸 Simplicity

Software shouldn't be difficult to use.

No unnecessary windows.

No endless configuration menus.

Everything should be easy to understand.

### ⚡ Automation

If a repetitive task can be automated, Sakura should handle it.

The launcher reduces repetitive setup while still allowing advanced users to configure everything they need.

### 🎨 User Freedom

Automation should never remove control.

Users can customize the launcher, edit themes, configure Wine and organize their library however they prefer.

# 🖥 Supported Applications

Sakura Launcher currently supports:

- Windows applications (.exe via Wine)
- Native Linux applications
- AppImages
- Flatpak
- Java (.jar)
- Shell scripts

Additional formats may be added in future versions.

---

# 🎨 Customization

Sakura includes a built-in theme system based on **HTML**, **CSS** and **JSON**.

Themes can be easily created, edited and shared without modifying the launcher's source code.

The goal is to make personalization accessible to everyone.
